Lesson 1

Understanding Documents

✓ Completed

What You’ll Learn

In this lesson, you’ll learn to recognize the basic parts of a document:

  • Document vs. page
  • Text
  • Paragraphs
  • Headings
  • Cursor/insertion point
  • Selecting text
  • Basic document structure
  • Opening a downloaded document
  • Basic saving and creating a separate copy

This lesson focuses on what each part of a document is and does, so the ideas carry over to whichever editor you use.

Why Start Here?

When we work with a document, we first need to understand what we are looking at. A client may send a document to clean up, update, organize, or review. Recognizing its structure helps us work carefully.

1. What Is a Document?

A document is a file containing information created, edited, organized, and presented in a document editor.

Kinds of documents include:

  • Notes
  • Instructions
  • Reports
  • Meeting information
  • Task lists
  • Letters
  • Simple work documents

A document can also contain different kinds of content, such as text, lists, tables, and links.

A document can be short or many pages long.

2. Document vs. Page

A document is the whole file. A page is one part of that document.

A three-page document is still one document.

Pages can shift as content is added or removed. Page breaks can therefore move while the document remains the same file.

Some web editors also offer a pageless view. The basic idea remains: the document is the whole body of information you are working with.

3. Text

Text can include words, sentences, numbers, dates, labels, instructions, and notes.

4. Paragraphs

In a document editor, a paragraph is everything from one press of Enter or Return to the next. This can include a short line, a heading, a list item, or an empty paragraph.

When text reaches the edge of the writing area and moves to the next line automatically, that is called line wrapping. You do not need to press Enter at the end of each visible line.

Paragraphs matter because they can be moved, deleted, copied, formatted, or spaced as units.

5. Headings

A heading identifies a section.

A heading is more than simply large or bold text. Its role is to identify the name or beginning of a section. Many editors provide built-in heading levels that can also help navigation tools recognize the document structure.

6. Pointer and Insertion Point

There are two things beginners often mix up:

  • Mouse pointer: the arrow or I-beam that moves when you move the mouse or touchpad.
  • Insertion point/cursor: the blinking position inside the document where typed text will appear.

The mouse pointer can move around the screen. The insertion point moves when you click in the document or use supported keyboard navigation.

Try this:

  1. Open a blank document.
  2. Type Hello!
  3. Click in the middle of the word.
  4. Notice the blinking insertion point.
  5. Type one character and observe where it appears.

7. Selecting Text

Selected text is shown with a temporary shaded background. This is not the same as applying a highlight color.

Selecting text identifies what you want to work with.

You may select text to:

  • Copy
  • Cut
  • Delete
  • Replace
  • Format

To select text, click and hold at the beginning, drag across the text, and release. Double-clicking often selects a whole word. Other selection methods vary by application.

Remember:

Select → Do something with the selection

8. Simple Document Structure

A useful basic model is:

Document → Sections → Headings + their content

A section may contain paragraphs, lists, tables, links, or other content.

9. Opening a Downloaded Document

Practice files may arrive as downloaded files.

In a desktop editor, you can usually open the file from your Downloads folder or from the location where you saved it.

In a web editor, you may need to upload the downloaded file first or use the editor's Open/Upload option.

Some editors first open downloaded files in a read-only, preview, or protected view. Look for an option such as Enable Editing or Open with… before you start. The exact wording and buttons vary by application. The important idea is:

Get the file into the editor before you begin editing it.

10. Saving Your Work

Different editors handle saving in different ways.

Editors with manual saving

Desktop editors commonly provide Save and Save As or a similar option.

  • Save keeps changes in the current file.
  • Save As / Save a Copy creates a separate version so the original can remain unchanged.

Editors with automatic saving

Many web editors save changes automatically as you work.

You may still need Make a copy, Save a copy, Download, or a similar option when you want a separate version.

The exact wording varies by editor.

For this module, the practical habit is:

Keep the original. Work on a separate copy. After making the copy, check the file name shown in the window or tab so you know you are editing the copy. Confirm where the finished copy is saved.

If a downloaded file is opened in a web editor, the editor may first ask you to upload or import it. That is a normal part of opening a local file in a web-based editor.

Try It — Identify the Parts

Use a simple example such as:

Monday Task List

A short paragraph explains the week's priorities.

Follow-up Items

Several related items appear below.

Identify:

  • Main heading
  • Paragraph
  • Section heading
  • List or list opportunity
  • Individual text

To change “Follow-up Items” to “Items for Follow-up,” select the heading text first.

Small Practice

  1. Create or open a blank document.
  2. Type My VA Task List, press Enter, then type a sentence.
  3. Add Next Steps, press Enter, then type three items on separate lines. You may use bullet points if you already know how; lists are taught later.
  4. Click different parts and notice the insertion point.
  5. Select a word or phrase and notice the selection.

The purpose is to become familiar with the document, not to produce a finished design.

Self-Check

  1. What is the difference between a document and a page?
  2. In a document editor, what is a paragraph?
  3. What is the purpose of a heading?
  4. What is the difference between the mouse pointer and the insertion point?
  5. Why might you select text?
  6. Can a document contain more information than is currently visible?
  7. Why might you create a separate copy before editing?
Show answers
  1. Answer: A document is the whole file; a page is part of that document.
  2. Answer: A paragraph is everything from one Enter/Return to the next.
  3. Answer: A heading identifies a section and helps show document structure.
  4. Answer: The pointer moves around the screen; the insertion point shows where text will be entered or edited.
  5. Answer: Selecting identifies the text you want to act on.
  6. Answer: Yes. More content may exist above, below, or on other pages.
  7. Answer: It keeps the original available while you work on a separate version.

Takeaway

A document has structure:

Document → Sections → Headings + their content

And a useful editing pattern is:

Select → Do something

Lesson 2

Navigating a Document

✓ Completed

What You’ll Learn

You’ll learn how to move around a document and locate the information you need.

You’ll practice:

  • Moving through a document
  • Recognizing where you are
  • Finding specific words or phrases
  • Moving to a section or location
  • Using zoom
  • Recognizing content outside the visible area
  • Confirming that a search result is the correct occurrence

Why Navigation Matters

A client may ask you to update information in a long document or check a particular section. Navigation helps us know where we are, where we need to go, and how to get there.

1. Moving Through a Document

Use scrolling to view earlier or later content. You may use a mouse wheel, scroll bar, touchpad, keyboard keys, or other supported methods.

Try scrolling through a document and back again. Notice that you are changing what is visible, not changing the document.

2. Knowing Where You Are

Look for clues:

  • Heading currently visible
  • Paragraph around the insertion point
  • Page currently displayed
  • Scroll-bar position
  • Section visible on screen

Before editing, ask:

“What part of the document am I looking at?”

3. Finding Specific Information

Most document editors provide Find or Search.

You can usually open it through the editor's Find/Search command. A common shortcut is Ctrl+F on Windows or Linux, or Cmd+F on Mac.

For example, search for Greenfield Supplies in a longer document.

If there are multiple matches, move between them and confirm which one is relevant.

Find locates information. It does not automatically change it.

Try It

Use a longer document or repeat a sample several times so that scrolling and multiple search matches are possible.

  1. Choose a word that appears more than once.
  2. Open Find/Search.
  3. Enter the word.
  4. Inspect the first result.
  5. Move to another result.
  6. Read the surrounding content.
  7. Confirm which occurrence you actually need.

4. Finding Is Not the Same as Editing

Finding locates information.

Selecting prepares text for an action.

Editing changes the text.

Useful pattern:

Find → Locate → Select → Edit

5. Moving to a Section

Some applications provide a navigation pane, outline, headings list, table of contents, or a Navigator.

These can help you move between sections when the document uses appropriate heading structure.

A heading that is merely made larger or bolder may not always work with navigation tools.

You’ll see how to apply a real built-in heading in Lesson 4.

6. Moving With the Insertion Point

Clicking in text places the insertion point at that location.

Try clicking near the beginning, middle, and end of a paragraph and observe the insertion point.

7. Zooming In and Out

Zoom changes how large the document appears on your screen. It does not normally change the actual font size.

Zoom in to read more comfortably; zoom out to see more of the document.

8. Content Can Be Outside the Visible Area

A document may contain more paragraphs, pages, tables, links, or notes above or below the current view.

Ask:

“Is there more information above or below this area?”

Try It — Document Navigation Practice

Create or use a document containing at least several sections:

Weekly VA Task Report

Completed Tasks

Updated product information
Reviewed customer messages
Checked inventory notes

Pending Tasks

Review supplier information
Prepare next week's report
Follow up on open requests

Notes

The supplier requested an updated contact list.

Repeat the sample sections if needed so the document extends beyond one screen.

Practice:

  • Scrolling
  • Clicking in Notes
  • Finding “supplier”
  • Moving between matches
  • Confirming the correct occurrence
  • Changing zoom

Practical VA Connection

Navigation can be used to find names, sections, instructions, requested changes, repeated information, or information needed before editing.

Self-Check

  1. What is the main purpose of scrolling?
  2. What does Find/Search help you do?
  3. What is the difference between finding text and selecting text?
  4. Why check surrounding content after finding a word?
  5. What does zoom normally change?
  6. If you can only see one section on screen, what should you remember?
Show answers
  1. Answer: Scrolling moves the visible area of the document.
  2. Answer: It locates specific text.
  3. Answer: Finding locates text; selecting identifies text to act on.
  4. Answer: A matching word may appear in more than one place.
  5. Answer: How large the document appears on screen.
  6. Answer: More information may exist above, below, or on other pages.

Takeaway

Know Where You Are → Find What You Need → Move to It → Confirm What You're Looking At

Lesson 3

Entering and Editing Text

✓ Completed

What You’ll Learn

You’ll learn to enter and change text.

You’ll practice:

  • Entering new text
  • Editing existing text
  • Selecting text
  • Positioning the insertion point
  • Deleting
  • Replacing
  • Copying and pasting
  • Cutting and pasting
  • Undo and redo
  • Checking results
  • Saving changes and creating a separate copy

Why Editing Matters

Clients may ask you to update dates, names, contact details, remove old information, or move information between sections.

Useful pattern:

Locate → Select or Position the Cursor → Edit → Check

1. Entering Text

Click where you want text, place the insertion point, and type.

If text is selected when you start typing, the selected text is normally replaced. If that happens accidentally, Undo can usually restore it.

Try It

Type:

Today's Tasks

Press Enter.

Type:

Review customer messages.

Then click inside the sentence and add a short word.

2. Editing Existing Text

Editing changes text already in the document, such as correcting a spelling mistake or updating a date.

3. Selecting Text Before Editing

Selecting identifies the text you want to work with.

Example:

Please review the inventory report before Friday.

You can then copy, cut, delete, replace, or format the selection.

4. Adding Text Without Selecting

Sometimes you simply position the insertion point and type.

Example:

Please review the report before Friday.

Place the insertion point before “report” and add “final” to produce:

Please review the final report before Friday.

5. Deleting Text

You can delete characters using Backspace or Delete, or select text and delete the selection.

A common keyboard distinction is:

  • Backspace usually removes the character to the left of the insertion point.
  • Delete usually removes the character to the right.

On some keyboards, especially Mac keyboards, the key labeled Delete behaves like Backspace.

After deletion, check the surrounding sentence.

6. Replacing Text

Select old text and type the replacement.

Example:

Meeting Date: June 18

Change to:

Meeting Date: June 20

If typing replaces something you did not intend to replace, use Undo and check the selection before trying again.

7. Copy and Paste

Copy stores a copy of your selected content. Nothing changes in the document until you paste.

Basic pattern:

Select → Copy → Move the Cursor → Paste

A common shortcut is Ctrl+C / Ctrl+V on Windows or Linux, or Cmd+C / Cmd+V on Mac. You can also use the editor's menu or context menu.

8. Cut and Paste

Cut removes selected content from its current location and keeps it available to paste elsewhere.

Basic pattern:

Select → Cut → Move the Cursor → Paste

A common shortcut is Ctrl+X / Ctrl+V on Windows or Linux, or Cmd+X / Cmd+V on Mac.

If you cut something and then cut or copy something else before pasting, the first item may no longer be the current item available for pasting. Undo can help recover the original if needed.

9. Pasting Carefully

Pasted text may bring formatting from its source. Notice whether it fits with surrounding content.

Advanced paste settings are out of scope.

10. Undoing a Change

Undo reverses a recent action.

A common shortcut is Ctrl+Z on Windows or Linux, or Cmd+Z on Mac. You can also use the editor's Undo command or Undo arrow.

11. Redoing a Change

Redo reapplies an action that was undone.

A common shortcut is Ctrl+Y on Windows or Linux, or Cmd+Shift+Z in many editors. Some Mac editors also use Cmd+Y.

Redo is generally available only while the editor still has an action that can be reapplied. A new change may remove that redo opportunity.

12. Check After You Edit

After changing text, confirm:

  • Correct information
  • Correct location
  • No accidental deletion
  • Sentence still makes sense
  • No missing information

Pattern:

Edit → Read the Result → Confirm

13. Saving Changes — Reminder

Save keeps changes in the current file. When you need to preserve the original, create and work in a separate copy as taught in Lesson 1.

Before finishing, confirm that the latest changes are saved and that you are working in the intended copy.

Try It — Basic Editing Practice

Create:

Weekly Task Update

The customer report is due on Friday.

Please contact Ana before the meeting.

The old contact number is [phone number].

Change:

  1. Friday → Monday
  2. Ana → Maria
  3. Replace the placeholder contact number with a different clearly fictional placeholder
  4. Read and check all sentences

Try It — Copy and Move Information

Create:

Task List

Morning

Check customer messages.

Afternoon

Prepare the weekly report.

Copy the customer-message sentence under Afternoon.

Then cut the report sentence and paste it under Morning. If moving a whole numbered line, remove any empty line or leftover number left behind. Press Enter to create a new line before pasting if needed.

Review the result.

Try It — Undo and Recover

Make a small change, undo it, inspect the result, and if appropriate redo it.

Practical VA Connection

Editing appears in client documents, reports, instructions, meeting notes, dates, names, contact details, and other simple document tasks.

Self-Check

  1. What does the insertion point indicate?
  2. When is selecting text useful?
  3. What is the main difference between Copy and Cut?
  4. What function would you normally try after accidentally deleting important text?
  5. What does Paste do?
  6. What usually happens if you type while text is selected?
  7. Why check after editing?
  8. Complete: Locate → ______ → Edit → Check
Show answers
  1. Answer: Where you are working or where text may be entered.
  2. Answer: When you want to work with a specific piece of text.
  3. Answer: Copy leaves the original; Cut removes it from the original location.
  4. Answer: Undo.
  5. Answer: It places copied or cut content at the insertion point, or replaces selected text if text is selected at the destination.
  6. Answer: The selected text is normally replaced.
  7. Answer: To confirm the correct information was changed and nothing else was accidentally affected.
  8. Answer: Select or Position the Cursor.

Takeaway

Insertion point (cursor) = Where you are working

Select → Do Something

Copy = Store a duplicate for pasting

Cut = Move

Undo = Reverse

Redo = Apply Again

Locate → Select or Position the Cursor → Edit → Check

Lesson 4

Basic Formatting

✓ Completed

What You’ll Learn

You’ll learn how basic formatting can make a document easier to read and understand.

You’ll practice:

  • Font
  • Font size
  • Bold, italic, underline
  • Alignment
  • Line spacing
  • Paragraph spacing
  • Headings
  • Basic emphasis
  • Consistency
  • Avoiding unnecessary formatting

Why Formatting Matters

Formatting helps the reader understand information.

1. Formatting Changes How Information Appears

Formatting changes presentation without necessarily changing the words.

2. Font and Font Size

A font is the visual design/typeface used for text.

Font size controls how large or small text appears.

Choose readable fonts and maintain consistency.

3. Bold, Italic, and Underline

Use emphasis with purpose.

Bold is often clear for short emphasis.

Italic can provide lighter emphasis.

Underline can be useful, but underlined text may be mistaken for a link. For ordinary emphasis, bold is often clearer.

If everything is emphasized, nothing stands out.

4. Text Alignment

Common alignment options include left, center, right, and justified.

Left alignment is commonly used for body text because it is easy to scan.

Justified text can create uneven spaces between words, especially in narrower lines.

Choose alignment based on the role of the content rather than decoration.

5. Line Spacing

Line spacing controls vertical space between lines within a paragraph.

6. Paragraph Spacing

Paragraph spacing controls space before or after paragraphs.

This is different from line spacing.

Pressing Enter repeatedly just to create large spaces is usually not the best way to control spacing.

7. Headings

Headings identify sections.

Most editors have a text-style list with options such as Normal text, Title, Heading 1, and Heading 2, although the names can vary.

Choosing a heading level from the editor's built-in heading feature marks the text as a heading, not simply as larger or bolder text.

Use heading levels in a logical order. For this foundation, the goal is simply to apply a recognizable built-in heading to section titles.

8. How Formatting Is Applied

Some formatting applies to selected text.

For example:

  • Font
  • Font size
  • Bold
  • Italic
  • Underline

Other formatting applies to the whole paragraph containing the insertion point or to selected paragraphs.

For example:

  • Alignment
  • Line spacing
  • Paragraph spacing
  • Heading level

To apply a heading level, place the insertion point in the heading line and choose the appropriate built-in heading from the editor's style list. To confirm that a heading is applied, click in the line and check that the style list shows the heading name. If sizes still differ afterward, use the font-size control to make them consistent.

The exact controls vary by editor.

9. Basic Emphasis vs. Decoration

Helpful formatting:

  • Clear headings
  • Readable font size
  • Consistent text
  • Appropriate emphasis
  • Reasonable spacing
  • Logical alignment

Potentially distracting:

  • Too many fonts
  • Excessive bold
  • Too many colors
  • Very large text without purpose
  • Inconsistent sizes
  • Decorative effects that reduce readability

10. Consistency Matters

Similar elements should generally follow the same formatting pattern.

11. Formatting Should Follow Structure

Understand the role of the information first, then use formatting to make those roles easier to see.

Format for the reader, not for decoration.

Try It — Format a Simple Document

Create:

Weekly VA Task Report

This week, the product information was reviewed and the customer messages were checked.

Completed Tasks

Reviewed product information.

Answered customer messages.

Pending Tasks

Check supplier information.

Prepare next week's report.

Apply:

  • A clear title
  • Recognizable built-in headings
  • Readable body text
  • Reasonable spacing
  • Limited emphasis
  • Consistent formatting

Try It — Formatting Cleanup

Use:

WEEKLY TASK REPORT

COMPLETED TASKS

THE PRODUCT INFORMATION WAS REVIEWED.

PENDING TASKS

PLEASE CHECK THE SUPPLIER INFORMATION.

Improve readability while keeping the wording the same.

You may retype text using normal capitalization. The goal is readable presentation, not learning a change-case feature.

Practical VA Connection

Basic formatting appears in reports, meeting notes, internal instructions, document cleanup, and other work documents.

Self-Check

  1. What is one main purpose of document formatting?
  2. What is the difference between font and font size?
  3. Why can excessive emphasis reduce readability?
  4. What is the difference between line spacing and paragraph spacing?
  5. Why are built-in headings useful?
  6. Describe one formatting approach that supports a readable work document.
  7. Before applying formatting, what should you understand first?
Show answers
  1. Answer: To help information become clearer and easier to read.
  2. Answer: Font is the visual design/typeface; font size controls how large it appears.
  3. Answer: It makes everything look equally important.
  4. Answer: Line spacing is between lines within a paragraph; paragraph spacing is between paragraphs.
  5. Answer: They identify sections and can help document structure and navigation.
  6. Answer: Any consistent, readable formatting that supports the document's structure is appropriate.
  7. Answer: The structure and purpose of the information.

Takeaway

Font = How text looks

Font Size = How large it appears

Alignment = Where text sits horizontally

Line Spacing = Space between lines

Paragraph Spacing = Space between paragraphs

Heading = Identifies a section

Principle:

Format for the reader, not for decoration.

Lesson 5

Working With Structured Content

✓ Completed

What You’ll Learn

You’ll learn to organize information using common document features:

  • Bulleted lists
  • Numbered lists
  • Choosing when a list is useful
  • Simple tables
  • Rows, columns, and cells
  • Links
  • Basic comments/suggestions awareness
  • Basic organization
  • Consistency

Why Structured Content Matters

A block of information can be difficult to scan. A suitable list, table, or other structure can make the same information easier to use.

1. Bulleted Lists

Bullets work well for related items where order is not important.

When you insert a bulleted list, the editor normally creates and manages the bullet marks for you.

Press Enter to move to the next item. Pressing Enter again on an empty list item normally ends the list.

2. Numbered Lists

Numbers work well when order or sequence matters.

To turn existing lines into a list, put each item on its own line (press Enter between items), select those lines, and choose the bulleted or numbered list option. If the lines already have typed numbers, remove those typed numbers so the editor's numbers do not double up.

Ask:

Does the order matter?

Let the editor create the numbers rather than typing the numbers yourself. Numbered lists can automatically renumber when items are added, removed, or moved.

3. Editing a List

Lists can be added to, deleted from, changed, moved, copied, or converted between list types.

4. Simple Tables

Tables organize information into rows and columns.

Example:

Task Status
Product review Complete
Inventory check Pending
Supplier follow-up Pending

Tables help when information has categories or fields that can be compared.

5. Working With Simple Tables

For this foundation, focus on:

  • Creating a simple table
  • Entering information
  • Moving between cells
  • Editing information
  • Adding or removing basic information
  • Recognizing a label/header row

Most editors provide an Insert → Table command or a similar table option.

A table is usually easier to work with when the first row identifies what each column contains.

The Tab key often moves to the next cell, and in many editors pressing Tab in the last cell creates a new row. Mouse or touchpad clicking between cells is also fine.

Advanced table design is out of scope.

6. Rows, Columns, and Cells

  • Row = horizontal
  • Column = vertical
  • Cell = one box where a row and column meet

7. Links

A link allows a reader to open another location such as a webpage, online resource, form, or other linked material.

The link text a reader sees can be different from the link address it opens.

For example, the text might say:

Open the PVA Academy page

while the underlying address points to a specific webpage.

8. Check Links Before Sharing

When a task requires link checking:

  1. Confirm the link is present.
  2. Check that the visible link text makes sense.
  3. Check the link address when the editor provides a way to view it.
  4. Open the link when appropriate and confirm that it reaches the intended destination.

Links often appear underlined or in a different color, but not always. Depending on the editor, hovering over the link, clicking it, or using a link-information/edit option may reveal the address. Some desktop editors require Ctrl+Click to open a link.

For this foundation, the important skill is checking the destination, not advanced link management.

9. Comments and Suggestions

Some applications allow comments and suggested changes.

You may see terms such as:

  • Comments — feedback, questions, or notes
  • Suggestions / Track Changes — proposed edits that may not yet be final

The terminology varies by editor.

In this module, we focus on recognizing these features and understanding that a suggested change may still need to be accepted before it becomes final text.

Advanced collaboration workflows are out of scope.

10. Choosing the Right Structure

Paragraphs, bullets, numbers, and tables each fit different information patterns.

Ask: Which structure will help the reader use this information?

11. Keep Structured Content Consistent

Similar items should generally follow similar patterns.

Try It — Organize Unstructured Information

Turn this:

“For tomorrow's work, check customer messages, review the inventory report, contact the supplier, prepare the weekly report, and send the completed file to Maria.”

into an appropriate structure.

A numbered list is appropriate if the sequence matters. A bulleted list may be appropriate if the order does not matter.

Try It — Choose a Structure

Decide whether a paragraph, bulleted list, numbered list, or simple table fits:

A. Documents required

B. Steps for a document review

C. Products with quantities and status

Show example answer guidance
  • A → Bulleted list because the items are related and order does not matter.
  • B → Numbered list because the steps follow a sequence.
  • C → Simple table because each item has multiple related fields such as product, quantity, and status.

These are examples of appropriate structures; the key is the reasoning behind the choice.

Practical VA Connection

Structured content appears in task lists, meeting notes, simple reference tables, links, comments, suggestions, and organized instructions.

Self-Check

  1. When is a bulleted list useful?

Takeaway

Bullets = Related items

Numbers = Sequence

Tables = Related information in rows and columns

Links = Connections to another location

Comments = Feedback or notes

Bring the Skills Together

We’ve worked through the basic skills needed to understand, navigate, edit, format, and organize a document.

Now use those skills together.

You will start with a downloadable starter document.

Canonical Practice Workflow

Open → Save a Copy → Inspect → Edit → Organize → Format → Review → Save

Saving a copy near the beginning protects the original while you work.

Your Task

  1. Open the starter document.
  2. Save a separate working copy before making changes.
  3. Inspect the document before editing.
  4. Navigate through the document and confirm where you are.
  5. Use Find/Search to locate a requested item.
  6. Make the requested edits.
  7. Copy one item to a second location.
  8. Move one item using cut and paste.
  9. Delete and replace the requested information.
  10. Organize information into appropriate lists and a simple table.
  11. Apply basic formatting and built-in headings.
  12. Check the included link and its destination.
  13. Review the finished document.
  14. Save the finished copy and confirm where it is saved.

The starter file is fictional, neutral, beginner-friendly, and free of real personal information. It contains a mixture of title/section information, notes, tasks, status information, a repeated name or term, a web link, simple edits, and information suitable for a table.

Step 2 — Save a Copy

Before editing, create a separate working copy.

Depending on the editor, this may be called:

  • Save As
  • Save a Copy
  • Make a Copy
  • A similar copy/version command

Choose a clear filename and confirm where the working copy is saved.

After making the copy, check the file name shown in the window or tab so you know you are editing the copy. Keep the original unchanged.

Step 3 — Inspect Before Editing

Read through the document before changing anything.

Identify:

  • Main topic
  • Sections
  • Headings
  • Related information
  • Repeated terms
  • Corrections
  • List opportunities
  • Table opportunities
  • Link
  • Inconsistent formatting

Step 4 — Navigate and Find

Scroll through the document.

Use Find/Search to locate the requested repeated term.

If there are several matches, read the surrounding content and confirm the correct occurrence before editing it.

Step 5 — Edit

Follow the Client Request box.

Use:

Locate → Select or Position the Cursor → Edit → Check

After each important change, read the result. When moving a whole line, remove any empty line or leftover number left behind by the move.

Step 6 — Organize

Turn information into:

  • A bulleted list where order does not matter (optional in this practice)
  • A numbered list where sequence matters
  • A simple table where information has related fields

Use a label/header row for the table.

Step 7 — Format

Apply:

  • A clear title
  • Built-in headings for section headings
  • Readable body text
  • Consistent font/size choices
  • Reasonable spacing
  • Limited emphasis
  • Appropriate alignment

Formatting should support the information.

Step 8 — Check the Link

Confirm:

  • The link is present.
  • The visible link text makes sense.
  • The link address is available for checking.
  • The link reaches the intended destination.

Use the editor's normal link behavior. Advanced link management is not required.

Step 9 — Review the Finished Document

Use this observable checklist:

  • Every requested change is complete.
  • The original starter document remains unchanged (if you used the downloadable starter file).
  • The working copy has a new, clear name.
  • The title is visually distinct from body text.
  • Section headings use the editor's heading feature.
  • The five Wednesday actions are in a numbered list.
  • Status information is organized in a table with a label/header row.
  • The link opens the expected destination.
  • Formatting is consistent enough to support easy reading.
  • The Client Request section has been removed before the final save (if you used the downloadable starter file).
  • No accidental deletions or unintended text remain in the work content.

Step 10 — Save and Confirm

Save the finished working copy.

If the editor saves automatically, confirm that the latest version is saved.

Confirm where the finished copy is located and that the original remains unchanged.
